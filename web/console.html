运行环境

填了就用于检测环境、分析、Dry Run 和广播。实时 Gas 始终走链上默认公开节点。

钱包

只填私钥，不要填地址。运行表只显示 wallet_1 / wallet_2，不会回显私钥。
每个 RPC 同时发这么多个钱包。优先打延迟最低的节点；一组打满再分给下一节点。钱包多于「节点数×并发」时，多出来的在已用节点上排队。
任一钱包回执为 SoldOut 时，未发出的全部停发；已经 broadcast 的仍等回执。

Mint 参数

需要后端 + OPENSEA_API_KEY。解析后覆盖链/合约；多阶段 drop 自动跟当前轮（预售→OpenSea mint，公开→mintPublic）。
填写后优先级最高。适合未验证合约，或自动获取失败时从 Etherscan / 项目方文档粘贴。

Gas 与启动

交易前对这一笔做 estimateGas，再加 20%。Robinhood 上 tip 和倍率锁定为 0，走链上最低价。重试次数仍可改。
单钱包预估将在检测后计算。多阶段 drop 启动后自动阶段追逐：无当前资格则等待下一阶段。

归集 NFT

只扫当前所选链上这个合约的持仓，不会查其他链。SeaDrop 等若 token 合约不同，在这里改。
到账后用这个钱包连 OpenSea 挂单。必须是你能导入的普通地址，不要填合约。
只转这些 ID。每个源钱包若不是 owner 会跳过。
不同源钱包可并行。同一钱包多枚 NFT 会串行，避免 nonce 冲突。
0 表示该钱包下范围内的全部。用于只转一部分。
